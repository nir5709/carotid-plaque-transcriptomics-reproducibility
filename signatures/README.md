# Gene signatures and markers

This directory contains the locked gene definitions used by the manuscript-facing analyses.

- `Inflammasome_source67.txt` — 67-gene source inflammasome set.
- `Inflammasome65.txt` — fixed 65-gene inflammasome signature represented in the GSE125771 discovery matrix and used for scoring/transfer analyses. The two source genes absent from the discovery matrix were `NLRP2B` and `PYDC5`.
- `Fibrous7.txt` — fixed seven-gene fibrous remodelling signature: `ACTA2`, `CNN1`, `MYH11`, `MYOCD`, `TAGLN`, `LMOD1`, and `ELN`.
- `RUNX2_SPP1.txt` — osteogenic markers `RUNX2` and `SPP1` used in the corresponding manuscript analyses.

The filenames are retained as stable computational identifiers because they are referenced by the analysis scripts. Public-facing text uses the biological names reported in the manuscript rather than the filenames themselves.
