# Results

This directory is reserved for compact manuscript-facing derived outputs and regression reports generated by the analysis workflows.

The principal release-validation output is:

`results/validation/reference_output_validation.csv`

which is generated by:

```bash
Rscript scripts/99_validate_reference_outputs.R
```

Large transient workflow directories and figure-rendering outputs are excluded by `.gitignore` unless a specific derived artifact is required for provenance. The authoritative raw transcriptomic source data remain the corresponding GEO accessions.
