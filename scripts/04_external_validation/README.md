# 04 — External bulk evaluation

This directory contains the manuscript-facing analyses used to evaluate the predefined transcriptional programmes across independent bulk transcriptomic datasets.

Subanalyses:
- GSE21545 — fixed-signature transfer and pairwise score correlations;
- GSE43292 — paired lesion-stage comparison;
- GSE163154 — segment-level comparison by intraplaque-haemorrhage status;
- GSE104140 — lesion-stage comparison and within-advanced-fibroatheroma calcification analysis.

Each workflow documents dataset-specific preprocessing, gene annotation, represented signature genes, the biological unit of analysis, statistical testing, and Benjamini–Hochberg multiple-testing correction where applicable.
