# Analysis scripts

The repository is organized around the analysis sequence reported in the manuscript. Run scripts from the **repository root** unless a script states otherwise. Raw GEO data are downloaded or reconstructed by dataset-specific workflows and are not redistributed here.

Two reproducibility routes are intentionally distinguished:

1. **Canonical manuscript reconstruction** — reproduces the numerical values reported in the manuscript using locked signatures and, where necessary, frozen historical mappings, intermediate tables, or derived outputs.
2. **Current-software reconstruction** — reruns public-data workflows under contemporary packages to assess executability and robustness. It is not substituted for the historical manuscript path when software or annotation drift changes numerical results.

## Canonical manuscript execution order

1. `00_install_dependencies.R` — install/check required R and Bioconductor packages.
2. `01_GSE125771_discovery/01_discovery_core.R` — locked scores, independent Top10/Bottom10 contrasts, limma DEGs, GO-BP ORA, MCP-counter context and k=2 NMF.
3. `02_WGCNA_NMF/01_whole_transcriptome_WGCNA.R` — whole-transcriptome WGCNA and module/signature associations; creates `Whole_transcriptome_module_assignments.csv`.
4. `03_cell_composition/01_MCPcounter_composition_adjustment.R` — composition-adjustment sensitivity analysis.
5. Historical CIBERSORT/LM22 manuscript summaries — no executable CIBERSORT/LM22 runner is distributed; the regression validator reads author-derived frozen summaries under `data/frozen/`.
6. `04_external_validation/GSE21545_fixed_signature_validation.R`.
7. `04_external_validation/GSE43292_paired_stage_validation.R`.
8. `04_external_validation/GSE163154_IPH_segment_validation.R`.
9. `04_external_validation/GSE104140_lesion_calcification_validation.R`.
10. `05_single_cell/GSE253903/03_stage2_frozen_reproduction.R` — canonical GSE253903 reconstruction from frozen donor × broad-cell-type pseudobulks.
11. `05_single_cell/GSE210152/03_frozen_historical_reproduction.R` — canonical GSE210152 reconstruction from frozen historical downstream tables. Run this driver with `Rscript`.
12. `99_validate_reference_outputs.R` — manuscript regression validation.

Final publication-figure assembly is intentionally outside the computational scope of this repository; the repository provides the underlying analysis outputs needed to reconstruct manuscript figures.

## Optional current-software single-cell routes

### GSE253903

`05_single_cell/GSE253903/01_stage1_QC_clustering.R` followed by `02_stage2_celltype_localization.R` reconstructs the public single-cell workflow from raw/public inputs. `00_repair_download.R` is a download-recovery utility.

### GSE210152

`05_single_cell/GSE210152/01_macrophage_state_analysis.R` reconstructs the public H5AD workflow with current Seurat/Harmony compatibility. Contemporary package versions can produce a different MNP clustering partition from the historical run; this route is therefore a current-software reconstruction rather than the canonical manuscript regression path.

## Locked discovery input

Discovery, WGCNA/NMF and MCP-counter use the manuscript GSE125771 matrix retained at `data/frozen/GSE125771_gene_level_matrix_frozen.csv`. This is the annotated, RMA-normalized, probe-collapsed gene-level expression matrix generated by mapping probe IDs to gene names and averaging RMA-normalized values when multiple probes mapped to the same gene. The final matrix contains 31,568 genes across 40 carotid plaques.

Downstream workflows use `Whole_transcriptome_module_assignments.csv`, generated by WGCNA. Brown/Blue module membership is fixed after discovery and is not redefined in validation cohorts.

## Third-party CIBERSORT / LM22 boundary

CIBERSORT and LM22 are not redistributed, and no executable installer or wrapper for them is included. Only author-derived historical summary tables are retained for manuscript regression. See `../docs/THIRD_PARTY_RESOURCES.md`.

## Statistical families

The manuscript workflow preserves the predefined statistical families used for multiple-testing correction:

- GSE21545: three pairwise signature correlations;
- GSE43292: three paired programme comparisons;
- GSE163154: three segment-level programme comparisons;
- GSE104140: four DIT-versus-advanced scores and four within-advanced calcification scores;
- GSE253903: three donor-balanced target-versus-other programme comparisons;
- GSE210152: the four-score exact donor-level family in the repaired historical workflow.

Additional analyses must be saved separately and must not overwrite manuscript outputs or alter the predefined multiplicity families.

## Regression validation

After canonical outputs are generated, run:

```r
source("scripts/99_validate_reference_outputs.R")
```

The validator writes `results/validation/reference_output_validation.csv` and stops when a checked value falls outside tolerance. Expected values, tolerances, input selection, and multiplicity families are locked to the manuscript analysis and should not be changed simply to obtain a passing result.

## Modular drivers

Long workflows are split into `parts/` or `*_parts/` directories. Normally run the top-level driver, which creates a shared analysis environment and sources modules in sequence.
